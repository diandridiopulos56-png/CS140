Explain the difference between an absolute link and a relative link. Why would you use relative links?

An absolute link points to a complete URL, including the protocol and domain name. It is used to link to external websites.

A relative link points to a file or page within the same website. It is used to link to other pages on the same site and is easier to maintain if the site structure changes.
